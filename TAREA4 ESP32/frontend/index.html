LEE LOS DATOS CON CONTEXTO

Captura híbrida RF + Red Local.

El sistema combina el escaneo multimodo del ESP32 (Wi-Fi promiscuo en canales 1–11 para todas las redes vecinas, BLE activo y BT Classic) con interrogación de red local (ARP, UPnP/SSDP, NetBIOS, PJLink e IPP/JetDirect) para extraer marca, modelo y clasificar en Celular/Tablet, Laptop, Smart TV, Audífonos, Impresora, Router o Cañón.

La distancia usa RSSI y requiere calibración. Las paredes, la orientación y la potencia de cada emisor cambian el resultado.

CONTROL DEL SISTEMA

Configuración

Los parámetros de radio se aplican al iniciar el siguiente ciclo. El firmware confirma con un ACK.

Calibración: coloca un emisor de referencia a 1 m, toma varias lecturas y usa su mediana como RSSI de referencia. Ajusta n comparando otras distancias conocidas. La calibración es global y no garantiza igual precisión entre equipos.

Requiere firmware 2.1.0+. El modo pasivo sigue disponible. Más información anunciada no garantiza identificar todos los equipos.

Asistente de calibración

Usa un emisor propio con dirección estable. Colócalo a 1, 3, 5 y 10 metros; mantén orientación y entorno. No se enlazan rotaciones de MAC.

Inicia una sesión para capturar lecturas.

Se requieren al menos 5 lecturas aceptadas en cada distancia. La calibración se aplica globalmente a las estimaciones, aunque cada emisor puede tener distinta potencia. Obstáculos y orientación generan incertidumbre.
