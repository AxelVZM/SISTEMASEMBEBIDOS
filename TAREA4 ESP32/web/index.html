Funciona aunque cierres el navegador

  1. Carga el firmware V7.3 en el ESP32 clásico con Arduino-ESP32 3.3.2 y partición Huge APP.
  2. Alimenta la placa por USB. La captura y el registro arrancan solos.
  3. Para observar desde el PC, cierra el Monitor Serie y conecta esta pantalla en Chrome o Edge.
  4. Para demostrar autonomía, alimenta desde una fuente USB estable; vuelve al PC y descarga el registro conservado.

La demostración usa datos simulados y se mantiene separada de las observaciones reales.

¿Por qué no aparece todo equipo electrónico?

Se escuchan tramas Wi-Fi de 2,4 GHz en canales 1–11. Los aparatos silenciosos, con radios apagadas o que usan otros protocolos/bandas pueden no detectarse.

¿Qué cuentan las direcciones observadas?

Direcciones recibidas en los últimos 60 s. Una MAC privada puede cambiar. Un mismo equipo puede usar varias direcciones Wi-Fi. No hay un total validado de equipos únicos.

¿Por qué faltan marca y modelo?

Solo se muestran como información complementaria cuando el emisor los anuncia. Se retiraron conexiones GATT/LAN, inventario y clasificador experimental. No se completan datos ausentes por suposición.

¿Por qué queda una fila sin recepción reciente?

La tabla conserva filas hasta que necesita reemplazar una antigua. El filtro «Recepción <60 s» las oculta. Sin nuevos anuncios no se confirma la presencia ni la ausencia física.

Accesorios opcionales

El firmware busca automáticamente OLED y RTC. La falta de estos accesorios no impide el conteo USB.

OLED: SSD1306, dirección 0x3C o 0x3D; SH1106 no está soportada. RTC: 0x68. Verifica el módulo RTC y su batería; algunos módulos incorporan circuito de carga y no admiten cualquier pila.

Patrones del LED

Un destello: operación normal. Dos: capacidad de una tabla alcanzada. Tres: revisar radio o almacenamiento. No detecta si el LED físico está instalado.

Reloj y fechas

La pantalla USB sincroniza la hora del PC automáticamente. Con DS3231 y batería adecuada se puede conservar tras apagar. Sin reloj válido, los registros usan el tiempo desde el arranque y dejan la fecha vacía.

Montaje repetible

Usa una carcasa no metálica, deja libre la zona de antena, fija altura y orientación, registra ubicación del sensor y evita apoyarlo contra metal. El soporte físico y la alimentación deben validarse en tu montaje.

Servidor EC2 · conectar y consultar el sensor

Esta página y la API están en tu EC2. Conecta el ESP32 por USB a este PC para transmitir, o consulta los datos que envía un puente USB de otro PC. No hace falta una red específica para detectar.

Ingresa el token y guarda. Después conecta el ESP32 o pulsa Ver sensor remoto.

El token permanece en sessionStorage de esta pestaña. El servidor recibe estados y observaciones, nunca la contraseña Wi-Fi. Sin ESP32 y un puente activo, se indicará que el sensor está desconectado.
Distancia estimada · calibración

Modelo d = 10^((A − RSSI) / (10n)). Valores iniciales orientativos, no medidos: A = −45 dBm, n = 2,5. Ajusta A con el RSSI medio de un equipo conocido a 1 m y n con mediciones a distancias conocidas. Se aplican a esta pestaña y no calibran automáticamente otros emisores.

Las paredes, antenas y potencia del emisor afectan el resultado. No indica ubicación ni vivienda. Sin mediciones de referencia no se asigna un porcentaje de error.

Tu red Wi-Fi y nube · opcional

El conteo funciona sin conectarse a ninguna red. Guarda aquí una red de 2,4 GHz para probarla o subir datos a AWS. Conectarse no revela la MAC de fábrica ni el modelo de los celulares. Durante la conexión/subida se pausa la escucha Wi-Fi.

Conecta USB con firmware 7.1 para configurar. La captura ya funciona sin red.

La clave queda en la memoria NVS de la placa; no se devuelve al panel ni se guarda en el navegador. Probar conexión no envía observaciones. Activar AWS sí las envía al destino configurado.
